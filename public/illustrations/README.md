# Empty State Illustrations

This directory contains SVG illustrations for empty states in the admin panel.

## How to Download Illustrations

Visit [undraw.co](https://undraw.co/illustrations) and download the following illustrations with primary color `#66bb6a`:

### Required Files:

1. **empty-products.svg**
   - Search: "shopping" or "empty cart" or "product"
   - Suggested: "Empty" or "Shopping"

2. **empty-banners.svg**
   - Search: "image" or "design" or "upload"
   - Suggested: "Add image" or "Pic profile"

3. **empty-blogs.svg**
   - Search: "blog" or "writing" or "article"
   - Suggested: "Blog post" or "Blogging"

4. **empty-videos.svg**
   - Search: "video" or "media" or "play"
   - Suggested: "Video files" or "Youtube tutorial"

5. **empty-exhibition.svg**
   - Search: "event" or "presentation" or "calendar"
   - Suggested: "Events" or "Conference"

6. **empty-orders.svg**
   - Search: "order" or "receipt" or "confirmed"
   - Suggested: "Order confirmed" or "Receipt"

7. **empty-users.svg**
   - Search: "team" or "people" or "group"
   - Suggested: "Team" or "People search"

## Steps:

1. Go to https://undraw.co/illustrations
2. Search for each illustration type
3. Click on the illustration you like
4. Set the primary color to `#66bb6a` (green to match the admin panel theme)
5. Click "Download" (SVG format)
6. Rename the file to match the names above
7. Place all files in this directory
